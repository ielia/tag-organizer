# Tag Organizer

A React + TypeScript frontend for organizing tags into ordered, color-coded groups.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18+)

### Install dependencies

```bash
npm install
```

### Run the dev server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```

### Preview the production build

```bash
npm run preview
```
